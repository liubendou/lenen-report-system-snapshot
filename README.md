# 乐恩报道管理系统

针对乐恩教育（河北专接本）线下课程的内部管理系统。**仅员工使用，无学生端。**
纯 Node.js（内置模块，零 npm 依赖），要求 Node ≥ 22.5（本机已装 v24 ✓）。

## 一分钟启动

```
node server.js                 # 默认端口 8800，环境变量 LENEN_PORT 可改
浏览器打开 http://<本机IP>:8800
默认校长账号：admin / change-me-on-first-login   ← 首次登录强制改密
```

数据都在 `data/` 目录（lenen.db 单文件 + 自动备份在 data/backups/）。

## 首次配置顺序（校长做）

1. 登录 → 改密码
2. 「岗位权限」：新建岗位（如 前台/宿管/副校长），勾权限点、选数据范围（全部/按班级）
3. 「员工」：两种加人方式——
   - 单个/Excel 批量导入（姓名+手机号[+岗位]）：账号=手机号，初始密码=手机号后 6 位，首次登录强制改密；岗位列填已有岗位名则直接激活
   - 员工自助注册（登录页「自助注册」）：真实姓名+账号+密码，提交后校长在此激活并分配岗位
4. 「学生导入」：下载模板 → 填好 → 导入（身份证号带校验码验证，性别自动从身份证推导）
5. 「宿舍」：建宿舍（楼栋/楼层/宿舍号/性别/**床位数人工输入**/坏宿舍标记）→ 报到日一键自动分配（缴费已齐者优先）→ 手动分配/调换

## 日常流程（对应八项功能）

| 功能 | 页面 | 说明 |
|---|---|---|
| 报到 | 报到 | 读卡器键盘仿真模式：光标点进输入框直接刷卡；新学生建档+**摄像头拍照**+手机号二次确认；重复报到会拦截 |
| 缴费 | 缴费 | 五项费用（报名/住宿/书/学费/押金）**纯人工登记**，金额可为 0；四项必缴齐才允许自动分宿舍（押金不阻塞） |
| 物资 | 物资 | 目录+逐人登记（已领/未领/缺+备注） |
| 发书 | 发书 | 发一本点一下（自动计数） |

## 学生状态机（系统骨架）

已导入 → 报到中(缴费/分宿未完) → 在训 ⇄ 请假中 → 离校办理中 → 已离校

## 权限说明

- 内置 23 个权限点（枚举），「自定义岗位」= 勾选权限点 + 数据范围（全部 / 指定班级）
- 校长是系统岗位（全权限），不可改不可删；校长账号 admin 不可停用
- 自助注册默认零权限（pending），激活才生效；离职员工「停用」不删除（保审计链）
- 涉钱（退押金）、涉分（改成绩）、涉密（员工/岗位/审计）权限默认不给任何岗位，校长显式授予

## 部署到服务器

### 方式 A：Windows 常驻（当前机器）
1. 管理员 PowerShell 进入本目录，运行：`node deploy\setup-tasks.js`
   （自动注册：开机自启任务 `lenen-autostart` + 每天 23:30 备份任务 `lenen-backup`，保留 30 份）
2. 防火墙放行端口：`netsh advfirewall firewall add rule name="lenen" dir=in action=allow protocol=TCP localport=8800`
3. 前台浏览器访问 `http://服务器IP:8800`

### 方式 B：Linux 服务器
```
拷贝整个目录到服务器 → 安装 Node ≥ 22 → 
LENNEN_DATA=./data node server.js   （数据目录环境变量是 LENEN_DATA；常驻可用 pm2 或 systemd 自己写 unit，Windows 用 deploy\setup-tasks.js）
```

### 恢复方法（数据出问题时）
1. 停服务（结束 node 进程）
2. 用备份覆盖：`copy data\backups\lenen-<时间>.db data\lenen.db`，并删除 `data\lenen.db-wal` / `data\lenen.db-shm`
3. 校验完整性：`node -e "console.log(new (require('node:sqlite').DatabaseSync)('data/lenen.db',{readOnly:true}).prepare('PRAGMA integrity_check').get())"` 应输出 ok
4. 重启服务，登录核对人数与金额

### 安全底线（重要）
- 身份证号是敏感个人信息：**服务器不要暴露公网**（内网/VPN 使用）；若必须公网，务必套 HTTPS 反向代理 + 强密码 + IP 白名单
- 界面默认脱敏显示身份证号；数据备份盘物理看管好
- `data/` 目录即全部数据，定期离机备份一份

## 技术

零依赖单体：Node http + node:sqlite（WAL）+ 原生前端。换机器 = 拷目录。

## v1.2.1 性能优化（弱网/慢链路友好）
- **gzip 压缩**：静态资源与 API 响应自动压缩，传输量约降 70%（300KB→约90KB）
- **分级浏览器缓存**：库文件与带版本资源长期缓存（二次访问 0 下载），入口页 no-cache 保证更新可达
- **全局顶部加载条**：任何请求进行中都有反馈（弱网不"像卡死"）
- **搜索竞态保护**：慢链路下旧的搜索结果不会覆盖新的
- SQLite synchronous=NORMAL（WAL 下安全提速写）
